# Niche Research Procedure

Goal: learn what works in this business's niche before designing. Be honest in
the brief: you can observe public structure, UX, copy, performance and SEO
signals. You cannot see any site's private ranking algorithm or analytics.

## 1. Find the benchmark sites (6-10 + 2-3 local)
Search queries to run (adapt to niche and city):
- "best [niche] website design", "[niche] website examples award"
- "top [niche] brands", "best [niche] in [city]" (local competitors)
- Awwwards / Godly / Siteinspire / Dribbble / Behance filtered by the niche
- Google top results for the main money keyword ("[service] in [city]")
Pick a mix: famous category leaders, award-winning designs, and the actual local competitors who rank on page 1.

## 2. Analyze each site (fetch the page; note, do not copy)
| Area | Capture |
|---|---|
| Hero | headline formula, primary CTA text, media type (video, 3D, photo) |
| Structure | section order, nav items, how many scroll screens |
| Conversion | booking/order/quote flow, sticky CTA, phone/WhatsApp, forms, pricing shown? |
| Trust | reviews, ratings, press, awards, logos, certifications |
| Visual | palette mood, fonts, imagery style, motion level, 3D use |
| Content | copy tone, menu/services/products presentation, FAQs |
| SEO | title/meta pattern, h1, schema.org types, local SEO (NAP, map, GBP link), blog |
| Tech/perf | framework hints, image formats, page weight, mobile experience |
| Weaknesses | slow, cluttered, hidden CTA, poor mobile, generic stock photos |

## 3. Niche cheat-sheet (starting hypotheses, verify via research)
- Restaurant/cafe: menu visible in 1 tap and crawlable text (not PDF), reserve/order button sticky, photos of real dishes, hours/map/phone above the fold on mobile, Restaurant + Menu schema, Google reviews, delivery links, events/private dining.
- Salon/spa/clinic: service list with prices and duration, online booking, before/after, practitioner bios, FAQs, trust badges.
- Real estate/interiors/architecture: project gallery with filters, case studies, process, enquiry form, virtual tour.
- Agency/SaaS: outcome headline, logo wall, case studies with numbers, pricing, demo CTA.
- E-commerce/D2C: hero product, fast PDP, reviews, bundles, shipping/returns clarity, 3D/AR viewer for product.
- Fitness/education: schedule or curriculum, trial offer, transformations/outcomes, coach profiles.
- Local services (plumber, lawyer, etc.): call button, service areas, license/insurance, reviews, quote form, emergency hours.

## 4. Write the Research Brief (keep to one screen)
1. Business snapshot (type, niche, city, audience, tier, primary action)
2. Benchmarks reviewed (list names/URLs)
3. Patterns that win (5-8 bullets)
4. Gaps to exploit (3-5 bullets: what competitors do badly)
5. Required sections and features (checklist driven by the findings)
6. Style direction (palette family, type, signature moment, with the reason)
7. SEO plan (primary keyword, local keywords, schema types)
8. Avoid list

## Rules
- Use at least 6 distinct sources. If search tools are unavailable, say so and fall back to the cheat-sheet, clearly labeled as assumption.
- Learn patterns, never copy layouts, copy, images, code or brand assets.
- Do not claim knowledge of competitors' algorithms or analytics; speak of observable signals.
- Respect robots.txt and site terms; no scraping at scale, no login-gated content.
